# Farming equipment mechanics and supported comparisons

This pass joins full visible inventory canonical IDs to the current Hypixel item list and local NEU lore/recipes. Display names are informational: legacy MELON and LOTUS IDs can carry renamed Tater and Peony names. The context exposes the NEU download timestamp, observed source, catalog name, reference lore, abilities, set bonuses, requirements and separate observed/template Fortune. Missing reference data stays unknown.

Supported comparisons require a direct nine-cell NEU crafting recipe consuming exactly one observed item, within the same armor/equipment slot or specialized tool family. Owned targets and targets with a recipe-linked owned successor are suppressed. No invented tier map, mismatched crop tool, cross-slot comparison, generic stat sorting or inferred missing loadout is used. Farmhand-to-Haymaker is not assumed to be a crafting upgrade. Recipes absent from this supported format remain uncovered.

Catalog Fortune differences are template differences, including any conditional/level-dependent values represented by that template, not effective gains over reforged/enchanted items. Set effects, pest bonuses, crop coverage and boot speed utility remain separate. Rancher's Boots receive a utility reminder and no automatic Fortune-based replacement. Tool level/rarity/gemstone configuration is not propagated to an upgrade.

Use requirements are checked through the shared evaluator. Craft unlocks, ingredients on hand, modifier transfer, full crafting cost and affordability remain unverified. Optional existing market snapshot quotes describe target acquisition, not recipe cost. Comparisons are INVESTIGATE references with null candidateId, not BUY recommendations. No paid Luna call is required for this pass.

Research boundary: the official Greenhouse release documents levelable tools, changed upgrade recipes, Helianthus above Fermento and farming armor pest/set changes: https://hypixel.net/threads/hypixel-skyblock-0-24-the-greenhouse.6027542/ . The official wiki closed in July 2026: https://hypixel.net/threads/end-of-the-official-hypixel-wiki-july-2026.6112020/ . Consequently old wiki pages and alpha release-candidate text are not pinned as current upgrade recipes; actual supported recipe evidence comes from the loaded item snapshot. A stale snapshot can still contain outdated recipes, so its timestamp and lore need live validation.

Validation: typecheck, full tests and targeted ESLint. Local profile inspection should verify Lemon's renamed armor/potato tool and Blueberry's Tater armor/Peony equipment/Melon Dicer. Inspect catalog date, matched mechanics, requirement status and direct recipe comparisons; zero matches means limited recipe coverage, not no upgrades. Further work before freeze: inspect these live joins and fill any real missing mechanics/recipe formats. A batch Luna check can follow only if the completed context needs behavioral validation.

## Follow-up: live Garden gates, quote freshness and replacement alternatives

Garden use requirements now read the separately fetched Garden level. A missing Garden level remains UNKNOWN; skill checks remain unchanged. Farming acquisition quotes expose ageHours and RECENT/STALE, with a 24-hour freshness threshold; future-dated quotes are also flagged STALE. Historical quotes require a fresh price check and never prove budget feasibility.

When no direct recipe target exists, armor/equipment may surface one same-slot catalog alternative with the smallest strictly higher template Fortune. This is labeled SAME_SLOT_CATALOG_ALTERNATIVE, not a crafting tier or proven effective upgrade. Only the strongest visible same-slot template is used for these alternatives, and owned targets/recipe successors remain suppressed. This extends early Farmhand armor and Peony equipment coverage without inventing a Farmhand-to-Haymaker recipe. Actual alternatives depend on the loaded catalog and may be requirement-locked. Specialized leveled tools receive no Fortune-only fallback.

Regression coverage includes reported/unknown/locked Garden gates, stale quote age, same-slot equipment selection, stronger owned baselines and leveled-tool exclusion. Next live inspection should confirm early armor alternatives and any Peony alternatives provided by the catalog, then assess remaining recipe/tool mechanics gaps before freeze. No new Luna call is required.
